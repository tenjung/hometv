# 집TV

개발 현황과 남은 작업: [2026년 11월 27일 업무일지](docs/work-log-2026-11-27.md), [2부: 외부 배포·Android TV 앱](docs/work-log-2026-11-27-part2.md), [3부: IPTV 재생 확인·보류](docs/work-log-2026-11-27-part3.md).

**외부 접속 주소: https://hometv-kappa.vercel.app** (Vercel + Neon). Android TV·폰 앱은 [`android/`](android) 와 [GitHub 릴리스](https://github.com/tenjung/hometv/releases)를 참고하세요.

PC와 Android TV / Google TV용 가족 영상 홈. React + TypeScript + Vite 프런트엔드, Cloudflare Worker API, D1 데이터베이스로 구성합니다. 영상은 원본 제공처에서 직접 재생하며 프록시·다운로드·봇 인증 우회를 하지 않습니다.

## 로컬 실행

Node.js 24 이상 필요. `npm install` 후 `.env.example`의 항목을 `.dev.vars`에 설정합니다. 가족과 관리자 PIN은 각각 숫자 6~12자리이며 같은 값도 사용할 수 있습니다. SESSION_SECRET은 32자 이상의 난수로 설정하세요. 이 파일은 Git에서 제외됩니다.

```powershell
npm run dev
```

PC: http://localhost:4317 . 같은 와이파이의 TV에서는 `http://PC의사설IP:4317`로 접속합니다. 브라우저 개발 서버를 외부 인터넷에 노출하지 마세요. Windows 방화벽이나 공유기 격리에 따라 TV 접근을 위한 별도 설정이 필요할 수 있습니다. 로컬 데이터는 `.local/hometv.sqlite`에 보관됩니다.

```powershell
npm test
npm run build
npm start
```

`npm start`는 빌드된 Worker를 로컬 Node 어댑터로 실행하므로 개발용 Vite 서버 없이 배포 결과를 검증할 수 있습니다. Windows에서 여러 서버를 동시에 실행하면 4317 포트가 충돌하므로 한 개만 실행하세요.

## 배포

`.openai/hosting.json`의 Sites 프로젝트와 `DB` D1 바인딩을 사용합니다. Sites에서 `FAMILY_PIN`, `ADMIN_PIN`, `SESSION_SECRET`을 비밀 환경 변수로 설정하고, 스킬의 소스 동기화·아카이브·배포 절차로 발행합니다. `drizzle/`의 생성된 마이그레이션을 함께 패키징합니다. 운영·로컬 DB는 별개입니다. 초기 링크는 첫 인증된 목록 조회 시 한 번만 등록됩니다. 삭제한 초기 링크는 다시 생성되지 않습니다.

Sites 비공개 배포는 플랫폼 로그인/접근 제어도 적용되므로 가족 PIN만으로 누구나 접속할 수 있는 배포와 다릅니다. 가족 기기에서는 플랫폼이 허용하는 접근 권한이 추가로 필요합니다. 일반 Cloudflare 배포를 사용할 경우 별도 도메인과 D1 바인딩·마이그레이션·비밀 환경 변수를 구성해야 합니다.

## 기능과 인터페이스

- `GET /api/session`, `POST /api/login`, `POST /api/logout`: 서버 인증, 서명된 HttpOnly 쿠키. 가족 세션 30일, 관리자 8시간. 로그인 실패 8회/10분 제한.
- `GET /api/channels`: 가족에게는 표시 중인 항목만 반환. 관리자는 숨김 항목 포함.
- `POST /api/admin/channels`, `PUT/DELETE /api/admin/channels/:id`: 관리자 전용. 수정·삭제는 revision 충돌 검사.
- `POST /api/reports`, `GET/DELETE /api/admin/reports`: 가족 접속 문제 기록·관리. 세션·항목·날짜별 중복 기록 방지.
- `PUT /api/admin/pin`: 현재 관리자 PIN 재확인. 숫자 6~12자리. 변경한 역할의 기존 세션 만료, PIN은 PBKDF2로 저장.
- 모든 변경 요청은 동일 출처 Origin을 검사합니다. API는 캐시하지 않습니다. 콘텐츠는 https 주소만 허용합니다.

즐겨찾기·최근 이용·TV 모드·다시보기 재생 위치는 기기 로컬 저장소에 보관합니다. 링크·순서·대체 경로·확인 상태·신고는 서버에서 공유합니다. TV 모드는 방향키 공간 탐색, 확인 선택, 브라우저 뒤로가기, 숫자 키패드를 제공합니다. 검색어 입력은 브라우저 키보드를 사용합니다.

내부 영상 화면에 포커스가 있으면 확인/Enter/Space로 재생·일시정지, 좌우로 다시보기 10초 이동, 위아래로 조작 버튼에 진입합니다. 표준 MediaPlay/MediaPause/MediaPlayPause 키를 처리합니다. 실시간 방송에는 되감기를 적용하지 않습니다. 전체화면에서 뒤로가기는 전체화면을 먼저 해제합니다. 모바일 조작 버튼은 최소 44px이며 음량은 기기의 음량 버튼과 음소거를 사용합니다. 실제 셋톱박스의 키 매핑은 기기에서 별도 확인해야 합니다.

## KBS 공식 라이브 (2026-11-27 추가)

KBS 공식 온에어의 공개 API(`cfpwwwapi.kbs.co.kr`, CORS 허용)에서 재생할 때마다 새 주소를 받아 집TV 안에서 재생합니다. TV 7개(1TV·2TV·NEWS 24·Story·LIFE·KIDS·WORLD), 라디오 5개(1라디오·해피FM·클래식FM·쿨FM·3라디오). KBS Drama·Joy는 KBS 복호화 키 서버가 외부 출처를 403으로 거부하므로 넣지 않았습니다. KBS 스트림(AES-128)은 Chrome 기본 HLS 재생에서 실패해 hls.js를 우선 사용합니다. MBC(외부 출처 "Not Allow")와 EBS(CORS 없음)는 우회하지 않고 외부 연결로 둡니다. 새 초기 목록은 `catalog_version` 으로 기존 DB에도 한 번만 추가되고, 삭제한 항목은 되살리지 않습니다.

## TV식 전체화면 플레이어

썸네일을 고르면 바로 화면 가득 재생합니다. 리모컨 **위 = 방송 정보**(편성·즐겨찾기·원본 사이트·신고·QR), **아래 = 채널 목록 띠**(좌우로 고르고 확인), 실시간 채널에서 **좌우·채널 키 = 이전/다음 채널**, 다시보기는 좌우 10초 이동. 뒤로 버튼은 패널을 먼저 닫고 그다음 목록으로 돌아갑니다(패널은 히스토리 `#watch-panel` 한 칸 사용).

## Google TV 앱 v1.5 · TV 화면 맞춤

- **앱 v1.5** (`android/`, versionCode 6): 집TV 시청 화면(`#watch`, `#watch-panel`)에서는 위쪽 주소창·툴바·진행 막대를 숨겨 영상이 화면 전체에 나오고, 목록으로 돌아오면 다시 보인다(`doUpdateVisitedHistory`). v1.4 앱도 새 웹에서 재생은 되지만 툴바가 위에 남는다.
- **TV 화면 맞춤**: Google TV WebView는 1920×1080을 CSS 960×540으로 그린다. TV 모드(`html.tv-mode`)에서 그 크기일 때 1280×720 기준 레이아웃을 75%로 줄여 홈 배너 아래 카드 줄이 여러 개 보이게 하고, 위쪽 메뉴는 불투명 배경으로 고정, 메뉴로 올라가면 맨 위로 스크롤한다.
- 2026-11-27 Mac의 Google TV 에뮬레이터(Android 14, `HomeTV_GoogleTV`)에서 v1.5로 확인: 리모컨으로 채널 선택 → 전체화면 재생, ↓ 채널 띠, 뒤로(패널 → 목록), KBS·SBS·삼성 TV 플러스 재생.
- 릴리스 서명 키는 Windows PC에만 있으므로 v1.5 릴리스는 그 PC에서 `powershell -File android\release.ps1 -Notes "..."` 로 만든다.

## IPTV (M3U · Xtream · 삼성 TV 플러스 · XMLTV 편성표)

관리 화면 → IPTV 탭에서 추가합니다. 가족 화면에는 IPTV 탭과 홈의 소스별 줄이 생깁니다.

- **M3U 주소**: m3u/m3u8 재생 목록. `#EXTM3U x-tvg-url` 의 편성표 주소도 읽습니다.
- **직접 입력**: M3U 내용을 붙여넣거나 한 줄에 `이름,스트림주소` / 스트림 주소.
- **Xtream 서버**: 서버·아이디·비밀번호로 `get.php?…&type=m3u_plus&output=m3u8` 와 `xmltv.php` 주소를 만듭니다. 비밀번호는 관리자 목록에도 다시 보여주지 않습니다.
- **삼성 TV 플러스**: i.mjh.nz 의 공개 채널 정보(`.channels.json.gz`)로 국가별 목록을 만들고 `https://jmp2.uk/stvp-{ID}` 로 재생, 편성표는 `https://i.mjh.nz/SamsungTVPlus/{국가}.xml.gz`. (게시글의 `all.m3u8` 은 2026-11 현재 404로 사라졌습니다.) 광고가 들어간 무료 방송 그대로입니다.
- **분류 보이기·숨기기**: 소스마다 그룹(예: 예능·쇼핑)을 꺼서 가족 화면에서 숨깁니다.
- **iptv-org 대한민국**: 공개 모음 목록 `https://iptv-org.github.io/iptv/countries/kr.m3u` 를 기본 소스로 한 번 넣습니다(삼성 TV 플러스 다음, 기존 DB에도 한 번만). 지우면 다시 생기지 않습니다. 죽은 주소가 섞여 있으니 추가 후 재생 확인을 돌리세요.
- **재생 확인 · 보류**: 소스 줄의 방패 버튼으로 채널을 40개씩 확인합니다(재생 목록 첫 부분·응답 형식만 보고 영상은 받지 않음). 응답 없음·404·웹페이지(로그인·미리보기 페이지 등) 응답은 **보류**로 옮겨 가족 화면에서 빠집니다. 다시 확인하면 살아난 채널은 돌아오고, 보류 목록에서 직접 풀면 다음 확인에서도 그대로 둡니다.
- **편성표(XMLTV, .xml/.xml.gz)**: 지금·다음 프로그램, 남은 시간, 진행률을 카드·채널 띠·정보 패널에 표시합니다. 서버가 −2시간~+26시간만 채널별로 보관하고 6시간마다 새로 받습니다.

재생 목록·편성표는 대부분 CORS가 없어서 서버가 대신 읽습니다(관리자만, 내부망·로컬 주소 차단, 크기·시간 제한). 리디렉션 주소는 재생 직전에 서버가 최종 주소만 확인해 주며(`/api/iptv/resolve`, 저장된 채널만), **영상은 서버를 거치지 않고** 기기가 직접 받습니다. https 스트림은 hls.js, http 스트림은 기기 기본 재생기를 씁니다. PC 브라우저(https 페이지)에서는 http 스트림이 막힐 수 있고, 안드로이드 앱(WebView 혼합 콘텐츠 호환 모드)에서는 재생될 수 있습니다. Stalker 포털은 아직 지원하지 않습니다.

## 외부 드라마 사이트와 광고

2026-11-27 상위 5개 확인 결과, 누누티비는 연결 초기화, HOOHOOTV는 반복 리디렉션, 콕콕티비는 봇 인증으로 확인이 제한됐습니다. 티비위키와 티비몬은 원본 사이트·플레이어의 중첩 iframe에서 실제 재생이 확인됐습니다. 이는 광고 없는 자체 플레이어 호환 확인과 다릅니다. 원본 플레이어의 광고·전용 세션 및 키 처리·제어 API 때문에 현재 요구사항을 충족하는 연결을 확보하지 못했으며 운영 목록에 재생 가능 항목으로 추가하지 않았습니다. 원본 플레이어를 변조하거나 인증·키를 복제하는 어댑터는 포함하지 않습니다. 집TV 자체 플레이어에는 사이트 배너나 팝업을 넣지 않으며, 영상 스트림 자체에 들어 있는 광고를 제거하는 기능은 제공하지 않습니다.

## 콘텐츠와 검증 한계

SBS 공식 `/live` 목록에서 TV 9개, 24시간 TV 8개, 라디오 3개를 추출해 등록합니다. `shared/sbs-catalog.mjs`에는 채널 이름·ID·그룹·공식 페이지와 공개 재생 지원 여부만 저장하며, 방송 토큰은 포함하지 않습니다. `npm run catalog:sbs`로 공식 목록을 다시 확인할 수 있습니다. 목록 변경 후 기존 DB의 항목은 관리자 API로 별도 반영해야 하며 임의로 덮어쓰거나 삭제하지 않습니다.

공식 채널은 SBS의 onair 정보 API에서 전체 세션의 로그인·지역·방송 제공 상태를 확인합니다. 화질 선택의 이용권 표시와 전체 채널 재생 조건을 구분합니다. 공식 플레이어가 제공하는 기본 미리보기 소스는 방송사 duration과 최대 60초 범위에서 재생하고 남은 시간을 표시합니다. 미리보기가 끝나면 재생·미디어 로드를 중단하고 공식 로그인 경로를 제공합니다. 같은 방송의 미리보기 기한을 탭의 sessionStorage에 기록해 재시도·닫기·새로고침으로 자동 연장하지 않습니다. 토큰은 저장하지 않습니다.

현재 목록은 공개 재생 4개(SBS BIZ, POWER FM, LOVE FM, 고릴라M), 공식 미리보기 14개, 공식 페이지 연결 2개입니다. SBS No.1 뉴스라이브는 응답에 재생 주소가 없고, SBS Plus 공식 채널은 방송 제공 제한 상태이므로 외부 연결을 유지합니다. 기존 별도 나는 SOLO 바로가기의 연결 방식은 유지합니다. 제공 조건은 바뀔 수 있으며 매 재생마다 다시 검증합니다.

나는 SOLO 라이브는 원본 페이지가 사용하는 SBS Plus 공개 재생 API에 브라우저가 직접 연결합니다. 재생할 때마다 만료 시간이 있는 HLS 주소를 새로 받고, SBS의 예상 호스트·경로·토큰 형식을 확인합니다. 영상 주소와 토큰은 DB나 소스에 저장하지 않습니다. 네이티브 HLS 또는 hls.js로 재생하고 재연결 시 주소를 다시 받습니다. 자동 재생이 제한된 브라우저는 재생 버튼을 사용하세요. 현재 편성된 SBS Plus 방송이 나오므로 항상 나는 SOLO가 방송되는 것은 아닙니다.

초기에는 사용자 제공 나는 SOLO 페이지, SBS·KBS·EBS 공식 페이지, KBS 다시보기, 주소월드 무료드라마 분류, MDN CC0 공개 MP4 샘플을 제공합니다. 외부 페이지의 무료 범위·로그인·지역 제한은 제공처에 따릅니다. 주소월드는 외부 링크 모음으로 연결하며 자동 수집하거나 스트림을 추출하지 않습니다.

## GitHub 동기화

`origin`은 https://github.com/tenjung/hometv.git 입니다. Sites는 별도 소스 저장소의 배포 이력을 유지합니다. 로컬 `main`에서 변경을 커밋한 후 `npm run sync:github`로 동일한 소스 트리를 GitHub `main`에 올립니다. `github-main`은 GitHub의 최근 소스 스냅샷을 추적합니다. GitHub에는 필요한 소스 스냅샷만 보내며 로컬 운영 설정, 데이터베이스, 빌드 산출물, 과거의 비공개 배포 이력은 보내지 않습니다. 기존 원격 변경은 확인하고 이어 붙이며 강제 푸시를 하지 않습니다.
