## 무료드라마 상위 5개 조사와 광고 처리

주소월드 목록의 상위 5개를 조사했다. 아래는 확인 당시의 상태이며 사이트 주소·접속 상태는 바뀔 수 있다.

| 사이트 | 확인 결과 | 운영 반영 |
| --- | --- | --- |
| 누누티비 | HTTP 연결 초기화 | 내부 재생 미등록 |
| 티비위키 | 원본 사이트와 중첩 플레이어 삽입에서 1080p 실제 재생 확인 | 광고 없는 자체 재생은 미확보, 미등록 |
| HOOHOOTV | 반복 리디렉션 | 내부 재생 미등록 |
| 콕콕티비 | 봇 인증·403 응답, 동일 출처 프레임 제한 | 내부 재생 미등록 |
| 티비몬 | 원본 사이트와 중첩 플레이어 삽입에서 1080p 실제 재생 확인 | 광고 없는 자체 재생은 미확보, 미등록 |

사용자는 광고 제거와 TV 리모컨 조작을 요구했다. 원본 사이트를 통째로 삽입하면 광고·원본 UI가 그대로 노출된다. 두 사이트의 플레이어에는 자체 광고와 전용 세션·키 처리가 있고 집TV의 기본 재생·탐색 버튼을 연결할 제어 API는 확인되지 않았다. 따라서 삽입 재생 성공을 광고 없는 자체 플레이어 완성으로 취급하지 않았고, 상위 5개를 재생 가능 항목으로 추가하지 않았다.

집TV 자체 플레이어에는 사이트 배너·팝업을 넣지 않는다. 영상 스트림 자체에 포함된 광고를 제거하는 기능은 구현하지 않았다. 원본 플레이어 변조, 인증·전용 키 처리 복제, 봇 인증 우회는 포함하지 않는다.

## TV 리모컨과 모바일 조작 개선

- 영상 화면에 포커스가 있으면 확인·Enter·Space로 재생·일시정지.
- 다시보기에서 좌우 방향키로 10초 이동, 위아래로 조작 버튼 진입.
- 표준 MediaPlay·MediaPause·MediaPlayPause·MediaRewind·MediaFastForward 키 처리.
- 실시간 방송에는 다시보기 탐색을 적용하지 않는다.
- 전체화면의 뒤로가기는 전체화면을 먼저 해제하고 이후 목록으로 복귀한다.
- 모바일 주요 조작 버튼을 최소 44px로 확대하고 작은 화면의 음량 증감 버튼을 정리했다.
- 실제 셋톱박스의 키 이벤트·전체화면·뒤로가기 동작은 기기에서 추가 검증해야 한다.

## 개발과 배포 운영

- React·TypeScript·Vite, Cloudflare Worker API, D1. 로컬은 Node.js 24의 SQLite 어댑터를 사용한다.
- `npm run dev`: 로컬 `http://localhost:4317`, API 4318.
- `npm test`: 자동 검증. `npm run build`: 타입 확인·프런트엔드·Worker 빌드.
- `.dev.vars`의 `FAMILY_PIN`, `ADMIN_PIN`, `SESSION_SECRET`은 Git에서 제외한다. 운영 값은 Sites 비밀 환경 변수와 서버 설정을 사용한다.
- `.local`의 DB, 임시 검증 서버, `node_modules`, `dist`, 배포 아카이브는 GitHub 소스에 포함하지 않는다.
- `npm run catalog:sbs`: 공식 채널 목록을 다시 추출한다. 기존 운영 DB에는 관리자 API로 별도 반영해야 한다.
- `origin`은 `https://github.com/tenjung/hometv.git`이다. Sites는 별도 소스 저장소를 사용한다.
- 로컬 `main`에서 작업을 커밋한 뒤 **`npm run sync:github`**로 GitHub `main`에 소스 스냅샷을 반영한다. `github-main`이 공개 저장소의 스냅샷을 추적한다. 로컬 배포 이력을 그대로 `git push origin main` 하지 않는다.
- Sites 배포는 제공된 소스 워크플로로 커밋·패키징한 뒤 비공개 버전을 배포한다. 프로젝트 설정은 `.openai/hosting.json`에 있다.
